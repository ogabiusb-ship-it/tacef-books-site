TACEF BOOKS — INSTALLABLE OFFLINE WEB APP
==========================================

WHAT THIS UPDATED PACKAGE CONTAINS
----------------------------------
This is the complete ready-to-host TACEF Books website. It contains the
English Manual, Yoruba Manual, Seed of Purpose Manual, automatic current-week
opening, PWA installation, bookmarks, manual search and local reading progress.
The app is configured for the Firebase project "tacef-books-manual".

The animated welcome book asks for the reader's name, remembers it only on that
device and then presents all three manuals. Every manual opens at its verified
page for the current week, while the home page previews the following week's
lesson. The Living Book reader includes horizontal phone swipes, edge-aware
mouse-wheel page turns, keyboard navigation, week navigation and animated page
turns. The reader has no sidebar. A slim, calm header keeps the manual title and
essential actions clear, while a fixed bottom control bar holds the current
week, current page, week list, saved places, A-/A/A+ sizing and fullscreen.
Nothing floats over the manual text. The header and bottom controls fade after
8 seconds on computers and phones, with top-edge or tap reveal, remembered text
sizing and fullscreen mode.
The spiritual sky theme changes automatically using the reader's local time:
sunrise and warm light from 5am, a calm blue daytime sky from noon, and a deep
blue moonlit atmosphere from 6pm. Lightweight rays, clouds, stars and restrained
cross geometry reinforce the Christian identity without distracting from text.
The manual reader itself uses a consistent dark navy surround in the afternoon
so no bright blue strip appears when its distraction-free header is hidden.
The professional release layer also reserves dedicated space for the top header
and bottom reading controls, preventing them from covering manual text. Library
anchors clear the sticky header, returning readers are not repeatedly interrupted
by the welcome book, and page selection uses an accessible in-app dialog.

PUBLISH WITH FIREBASE AND GITHUB
--------------------------------
1. Extract this ZIP on your computer.
2. Copy every item INSIDE the extracted package into the ROOT of the existing
   tacef-books-site repository. Do not place the ZIP or website files inside
   .github/workflows. Do not delete the hidden .git folder.
3. In the repository terminal, run:
     npm install -g firebase-tools
     firebase login --no-localhost
     firebase init hosting:github
4. When prompted, choose the existing Firebase project "tacef-books-manual",
   the GitHub repository "ogabiusb-ship-it/tacef-books-site", automatic deploys
   for the main branch, and do not overwrite index.html.
5. Commit every new or changed file, including the generated workflow files:
     git add -A
     git commit -m "Configure Firebase Hosting"
     git push origin main
6. GitHub Actions will publish the app. The expected free address is:
     https://tacef-books-manual.web.app

For a first manual deployment after signing in, run:
     firebase deploy --only hosting

INSTALL ON A DEVICE
-------------------
Android or desktop Chrome/Edge:
- Open the published site and select Install app.

iPhone or iPad:
- Open the site in Safari.
- Tap Share, then Add to Home Screen.

USE WITHOUT INTERNET
--------------------
Open the installed app while online and choose Save offline on each manual
you want to retain. The app, manual search, bookmarks and selected manuals will
then remain available on that device without internet access.

IMPORTANT
---------
The reader name, preferred reading size, progress, bookmarks and offline PDF
downloads are stored separately on each device. Clearing the browser's site
data removes these locally saved preferences and downloads.
